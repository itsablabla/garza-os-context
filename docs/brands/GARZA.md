# Garza (GRZ) — Brand Overview

**Code:** `GRZ` · **Primary domains:** `garza-os.com`, `garzaos.cloud`, `garzaos.online` · **Color in index:** Garza 29 sessions

Garza is the personal/family/home OS layer. It spans home automation, personal finance, school/family logistics, and the MCP / automation plumbing that wires those into Fabric AI and Nextcloud.

## Credentials / env var convention

Garza services expect secrets named `GARZA_*` or `GRZ_*` in the session/org secret store. If a new Garza-scoped secret is added, prefix it with `GARZA_` so it shows up naturally in the secrets list.
